# Images

(matching what `index.html` and the project pages currently reference as
placeholders):

- `headshot.jpg` — About section photo
- `rocket-software.jpg`, `rocket-airbrake.jpg`, `thesis.jpg`,
  `ros-research.jpg`, `controls-final-project.jpg`,
  `senior-design-project.jpg` — one cover image per project (used in both
  the homepage grid card and that project's detail page)

Once added, swap the `[ image / video ]` placeholder `<div>` in the
relevant page for an `<img src="assets/images/....jpg" alt="...">` (use a
`../` prefix from inside `projects/*.html`).
