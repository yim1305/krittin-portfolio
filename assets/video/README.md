# Video

Put project video clips here (or skip this folder and just link to a
YouTube/Vimeo embed instead — either works). If using local files, an
`<video>` tag replacing the `[ image / video ]` placeholder works well:

```html
<video src="assets/video/rocket-airbrake.mp4" controls muted playsinline></video>
```

Keep files reasonably small (a few MB, not hundreds) — GitHub has a 100MB
per-file limit and large videos will make the repo slow to clone. For
longer/higher-res footage, host it on YouTube/Vimeo unlisted and embed
that instead.
